# Bauble Blast

Play Bauble Blast on any static website. Upload the contents of `dist/` to a site folder and open its `index.html` over HTTP or HTTPS. Keep the `assets/` folder alongside it. The build works at a site root or a subfolder.

The game-over screen shows the run score and the high score saved in that browser for the site.

To rebuild from source, run `npm ci` followed by `npm run build` in this folder. Use `npm run dev` for local development.
